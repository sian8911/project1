# Nyan Cat 3D Space

Three.js를 활용하여 우주 공간을 공전하는 3D 냥캣(Nyan Cat) 애니메이션 웹 프로젝트입니다.

## 🚀 프로젝트 개요
- **기술 스택**: HTML5, Three.js (r128), JavaScript
- **주요 기능**:
  - Three.js 복셀(Voxel) 스타일로 구현된 3D 냥캣 모델 및 무지개 꼬리
  - 우주 배경의 반짝이는 별빛(Stars & Sparkles) 파티클
  - 각기 다른 크기와 속도로 궤도를 공전하는 3마리의 냥캣
  - 마우스 드래그를 통한 360도 카메라 시점 회전 및 휠 줌(Zoom In/Out) 조작

## 🎮 실행 방법
별도의 빌드나 서버 설정 없이 `index.html` 파일을 웹 브라우저(Chrome, Edge 등)에서 바로 열어 실행할 수 있습니다.

## 🕹️ 조작 방법
- **시점 회전**: 마우스 좌클릭 후 드래그
- **줌 인/아웃**: 마우스 휠 스크롤
